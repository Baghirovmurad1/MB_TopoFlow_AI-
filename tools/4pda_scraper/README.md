# 4PDA topic scraper

Выгружает все сообщения темы форума 4PDA (например, `showtopic=603033`, 89 страниц)
в список модулей: заголовок, описание, автор, дата, ссылки.

Только стандартная библиотека Python 3.8+.

## Запуск

```bash
python3 tools/4pda_scraper/scrape_4pda.py --topic 603033 --pages 89
```

Параметры:

| Флаг | По умолчанию | Смысл |
|------|--------------|-------|
| `--topic` | `603033` | id темы |
| `--pages` | `89` | сколько страниц скачать |
| `--per-page` | `20` | сообщений на странице (шаг `st=`) |
| `--out` | `output/topic_<id>` | папка результата |
| `--delay` | `1.0` | пауза между запросами, сек |

## Результат

- `<out>/modules.md` — читаемый список: `## N. Заголовок`, метаданные, описание, ссылки.
- `<out>/posts.jsonl` — по одной записи на сообщение: `post_id`, `page`, `author`,
  `date`, `title`, `description`, `links`.
- `<out>/cache/page_NNN.html` — сырой HTML каждой страницы.

Скрипт кэширует страницы: если запуск прервался, повторный запуск докачает только
недостающие. Дубликаты (по id сообщения) отбрасываются.

## Если сообщения не находятся

Разметка форума может отличаться от ожидаемой. Тогда скрипт пишет
предупреждение с путём к сохранённой странице. Откройте её, найдите классы
контейнера сообщения, автора, даты и текста, и поправьте множества
`POST_CLASSES`, `AUTHOR_CLASSES`, `DATE_CLASSES`, `BODY_CLASSES` в начале скрипта.
Кэш не нужно удалять: парсер перезапускается по уже скачанным файлам.
